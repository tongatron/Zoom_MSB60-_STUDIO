About the patch files

The .zptc format was reverse-engineered from exported patches and is not supported by ZOOM. Parameters marked "unverified" use an inferred encoding. Patches were tested on Zoom MS-60B+ firmware 1.20. How it was done: Technical notes.

Still to check

  • Amp MID-FREQ (32 Hz – 6.3 kHz): the 32 knob steps were read on the AMPG SVT, on the pedal's display. SMR400, B-MAN100 and AC 370 are assumed to use the same steps.
  • PRM2 block: only the selected slot and the amp slots are decoded; the rest of the patch data is copied from a reference export.
  • "Big Black" export: its first effect was exported with an unknown ID (0x09000020 instead of 0x01000020 for BLACK OPTICAL COMPRESSOR). A new export is needed to tell a flag from an export defect.
  • Pedal manager: the USB commands come from zoom-zt2 and are not documented by ZOOM. Every write is backed up and read back.

Unverified encoding

The rule from displayed value to stored value is inferred by analogy. The builder marks these parameters "unverified": check the value on the pedal after importing the patch.

Not decoded

The encoding is unknown: the builder asks for the stored value ("raw") instead of the value shown on the pedal.
